How these examples are generated

Each image is built from a fixed recipe and seed, then checked for containment, collisions, angle limits and rival clearance. The displayed node count is the achieved result; dense or narrow regions can stop short of the requested target. Boundary following and terminal anchoring are experimental.

Download generation measurements and environment details (JSON). PNG and SVG use the same geometry. Colour previews can differ slightly between screens and renderers.
