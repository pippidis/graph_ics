Dimensions, maps, boundaries and lettering

Each example is a complete downloadable JSON or YAML scene. Edit its values, then pass it to render --config or frames --config. Coordinates and dimensions use world units; output scale controls pixels per world unit.

Ring wall = outer radius minus inner radius. A hollow circle needs inner diameter × output scale large enough to see; a one-pixel wall is a useful starting point. A letter stroke must be wider than twice the outer radius to fit a node, and longer than two radii plus two gaps plus the visible edge length to fit a connection. Increase the font size or reduce geometry dimensions for thin strokes. Fonts are resolved locally, so use the same installed font to reproduce outlines across machines.

Boundary files accept GeoJSON Polygon or MultiPolygon, including holes; a file path resolves relative to the scene. text_region uses glyphs as the allowed region; texts[].exclusion_mode: glyph excludes glyphs instead. Border strokes are centred on the supplied boundary and do not add collision padding. Density is a packing request, not an exact count.

Watch the graph grow

A complete 480-node growth run, followed by a pause on the finished artwork. Use Play animation to watch the sequence, or pause to return to the completed artwork. Download GIF or download the event log.

Higher fps gives more samples of the same timeline; seconds per event changes speed. GIF needs an opaque background and has a limited colour palette; use PNG frames for transparency and full colour. The exporter rejects oversized frame or pixel budgets before rendering.

graph-ics frames --log docs/example-growth.jsonl --gif --palette porcelain --fps 15 --seconds-per-event 0.015 --max-frames 300 --output examples/output/growth.gif

Commands and files

list and describe print information; render writes one PNG/SVG, optionally with a JSONL log; frames writes a numbered PNG sequence; gallery writes this library. --force only permits overwriting render outputs. --quick selects the six-scene smoke gallery; this controls page is still included. --output chooses their location, without altering the artwork.

graph-ics list
graph-ics describe density
graph-ics render --help
graph-ics gallery --output examples/gallery

All generated figures sit in figures/ below the gallery index. Open the PNG/SVG links above to compare file formats visually.
