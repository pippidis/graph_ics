Nodes and connections

Node dimensions and connection rules determine the texture of the artwork. Compare the same kind of graph with different walls, spacing and angles.

On this page
  • Radius, wall and spacing
  • Node shapes
  • Connection patterns
  • Angle restrictions

Radius, wall and spacing

Ring wall thickness is outer radius minus inner radius. Connection gap separates a line from its endpoint nodes; buffer reserves clearance from unrelated geometry. Length settings describe the visible connection.

Fine Rings

Radius 3, inner radius 2.5: a 0.5-unit wall.

650 nodes of 650 requested. Stop: target_reached. 240/240 occupied tiles; 100.0% of tile area has a node. This is a coarse coverage measure, not solid ink coverage.

Node shapes

These vary only the visible node outline. Shape choice is preserved by replay.

Same layout and outer radius. Polygon corners fit inside the reserved circle; endpoint gaps can therefore look larger.

Angle restrictions

Hard rules forbid small junctions; soft penalties merely make them less likely. Stricter settings change the subsequent random growth and can reduce coverage.

Angles Free

Hard minimum 0 degrees; preference 0; penalty 0. Identical seed and target, different rejection decisions.

632 × 432; 480 nodes

Reproduce / SVG
graph-ics render --example sprawl --palette porcelain --nodes 480 --seed 7 --node-shape circle --edge-style solid --scale 1 --margin 16 --minimum-angle 0 --preferred-angle 0 --angle-penalty 0 --output examples/output/angles-free.png
SVG
