All command-line options
OptionWhat it doesExample
--fill-areaSearch unfilled space with periodic reseeding; nodes remains a safety cap. Stops report exhausted search or limits, not complete packing.Visual example
--configLoad a complete JSON/YAML scene; file paths resolve beside that scene.Visual example
--gifExport an opaque looping GIF instead of individual PNG frames.Visual example
--node-inner-radius / --node-outer-radius / --node-bufferInner and outer ring radii, and clearance to unrelated geometry, in world units.Visual example
--edge-thickness / --edge-node-distance / --edge-length-min / --edge-length-maxFull stroke width, ring-to-line gap, and visible length range in world units.Visual example
--exampleSelect a documented recipe; list shows names and describe explains it.Visual example
--paletteChoose colours for the complete scene; geometry stays the same unless text width changes.Visual example
--seedChange the random layout; reuse the seed to reproduce it.Visual example
--nodesRequested total population including seeds. Constraints can stop growth below it.Visual example
--node-shapeCircle, square, diamond, triangle or hexagon; hollow unless inner radius is zero.Visual example
--edge-styleSolid, dashed, dotted or double lines inside a collision-protected corridor.Visual example
--minimum-angleHard ban below this incident angle in degrees; straight continuation is 180.Visual example
--preferred-angleSoft angular target; must be at least the hard minimum when nonzero.Visual example
--angle-penaltyStrength from 0 to 1 of soft rejection below the preferred angle.Visual example
--scaleOutput units per world unit: larger image, same geometry. Compare native dimensions below.Visual example
--marginWorld-unit whitespace around the region, scaled with the image.Visual example
--transparentLeave the background transparent. Checkerboard indicates alpha in these previews.Visual example
--outputPNG/SVG file for render; new folder for frames; gallery folder for gallery.Visual example
--recordSave accepted events as JSONL while rendering; later replay needs no growth rerun.Visual example
--logRead recorded geometry for frames. Recipe, seed and node target do not rebuild it.Visual example
--fpsFrames per second. More samples make the same event timeline smoother.Visual example
--seconds-per-eventIncrease to slow the recorded growth; each event is given this duration.Visual example
--max-framesSafety cap: an oversized frame sequence is rejected, not silently truncated.Visual example
--forceAllow render to replace its existing image or recording; does not affect appearance.Visual example
--all-palettesExpand every regular recipe across all ten palettes instead of the curated selection.Visual example
--quickGenerate six small scenes plus this controls guide; omit for all recipes and large examples.Visual example
--help / -hShow command-specific usage and defaults; no image is generated.Visual example
